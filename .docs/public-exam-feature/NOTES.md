## Главные правила

Период проведения произвольный. Преподаватель готовит вариант и сеансы, публикует; его ученики по предмету могут записаться на один сеанс. Управление у владельца и администратора. Родитель только смотрит. Control остаётся в курсе.

Гость получает разбор сразу после сдачи. Ученику центра баллы и разбор доступны после утверждения работы. Никакого ожидания завершения всех сеансов и обязательного резервного варианта.

При сеансе 10:00–13:55 не начавший к 13:55 считается не пришедшим, его бронь аннулируется. Начавший получает 3:55 от фактического старта: в 11:00 начал → до 14:55 работает. Время личной попытки и плановый конец — разные поля.

Преподаватель отменяет не начатую запись с причиной; ученик затем выбирает будущий сеанс с местом. Самоотмена/перенос до начала своего сеанса. Старая бронь при переносе сохраняется до подтверждения новой. Листа ожидания нет.

Уведомления исключительно в кабинете ученика/родителя. Гостям нет email, OTP, автоматических сообщений. Сотрудник вручную выдаёт персональный вход по принципу JOIN и отдельно отправляет ссылку результата в мессенджере. Подбор по ФИО/телефону сам по себе доступ не даёт.

Гость — отдельный участник с необязательным Person; не зачисляется в LMS. Источник «школа/преподаватель» служит для группировки, а право внешнего просмотра выдаётся только по выбранным участникам и отдельному согласию.

27 единиц КЕГЭ, максимум 29 первичных; №26 и №27 по 2. По текущей шкале проекта 18 первичных = 72 вторичных, 22 = 83. Домашних тренировок нет.

## Дизайн

Задания — существующие `sum-task` из «Работ»: компактная шапка, вердикт, балл справа, условие, ответ, эталон при ошибке, решение. Полный разбор — отдельный экран; общие расширения применяются также в «Работах».

Календарь и поповеры — настоящие компоненты КТП/индивидуальных занятий. Карточки и лента — из «Моих курсов». Публичные страницы — тема и текущие сайдбары/CTA. Нельзя копировать в приложение стили, навигацию, шрифты и заглушки HTML-мокапа.

## Границы макета

Демонстрационные данные, локальное состояние. Секретные ссылки, права, согласия, бронь в БД, часы, уведомления, печать и реальные экзамены здесь не реализуются. Плеер показан схемой интеграции; в разработке остаётся существующая станция. Состояния переключаются вручную для просмотра. Условий-примеров несколько, в продукте выводится полный реальный вариант.

Ранние предложения из предыдущей версии NOTES (OTP, email, 15 минут после старта, ожидание последнего сеанса) **отменены**, не использовать их при разработке.

## Последние правки макетов

- Только очные сеансы, без онлайн-формата.
- Форма записи остаётся обсуждаемым черновиком, не окончательным UI-заданием.
- «Проведение экзамена» — первый пункт «Мои экзамены» преподавателя.
- В школьном отчёте работа раскрывается под таблицей на той же странице: навигация по заданиям, затем задания.
- Карточки показателей в отчёте и статистике выровнены по размерам.
- Плеер-схема удалён; используется существующая станция.
