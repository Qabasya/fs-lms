# Экзамены — актуальная памятка

Обновлено 2026-10-02.

- [SPEC.md](SPEC.md) — задание агенту, сценарии, данные, права, оплата, гонки и приёмка.
- [DECISIONS.md](DECISIONS.md) — подтверждённые решения и отдельно предложенные настройки.
- [E2E-REVIEW.md](E2E-REVIEW.md) — путь гостя/ученика/родителя, ошибки и ручные сценарии проверки.

Гость: приглашение школа/класс/преподаватель (ссылка с ключом, noindex, без капчи — гости с VPN) → форма → временная бронь → WooCommerce → серверное подтверждение → запись → вход от сотрудника → станция → немедленный разбор → личная ссылка результата. Переносы лично, возврат при полной неявке вне WooCommerce; бесплатный допуск — только купоном Woo; о проблемных оплатах уведомляются администраторы платформы (`lms_office`). Письма магазина сохраняются.

Ученик: кабинет → выбор и подтверждение сеанса без гостевой оплаты → расписание/уведомления → станция → ожидание утверждения → результат. Родитель только смотрит. Контрольные остаются шагами курса.

Оплата, запись, допуск, попытка и ручной возврат — разные состояния. Неявка в конце планового сеанса только без старта; начавшему полная длительность. Очный формат. Перерешивания нет.

HTML-мокап отстаёт от новых решений по оплате и части ранее изменённых требований; это иллюстрация, не точный источник задания. Эта редакция обновляет документацию, не внедряет WooCommerce-интеграцию и не утверждает, что реальные тесты оплаты пройдены.

- [RESEARCH.md](RESEARCH.md) — карта существующего кода.
- [index.html](index.html) — имеющийся прототип; обновление его платёжного сценария не выполнялось в этой задаче.
