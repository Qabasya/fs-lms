# Макет: что проверено и из чего собран

2026-10-02. Макет (`index.html`) подключает настоящие стили плагина и темы (`assets/css/*.min.css`, `fs-lms-theme`) и настоящую разметку шапки, подвала, сайдбара и меню кабинета (`real.js`, `site-inline.css`). Открывается локально после `npx gulp build`. Состояния экрана переключаются в панели «Экраны макета».

Проверено: все 13 экранов и их состояния на 1440 px, ключевые — на 390 px; клик по каждому действию на каждом экране без ошибок JavaScript. Не проверялись БД, права, WooCommerce, таймер станции и безопасность ссылок — их критерии в SPEC.md.

## Новое (нет готового аналога; помечено «НОВОЕ» в `style.css`)

1. Карточка даты в карусели выбора даты и времени (крупная: дата, день недели, время, кабинет, места) — одна и для кабинета, и для сайта; вернули вид из прошлого макета, потому что плитка `sc-tab` слишком скудно показывает сеанс. При реализации на сайте — Splide темы.
2. Резюме перед оплатой («ключ — значение»).
3. Строка обратного отсчёта брони (можно вывести внутри `fs-apply-card__status`).
4. «Жёлтый» вариант пилюли статуса (в кабинете только зелёный, синий, серый).
5. Вердикт «Частично верно» (в `sum-verdict` только верно, неверно, на проверке).
6. Блоки из прошлого макета для результата и отчёта: шапка результата (балл + шкала), квадратики отметок заданий, метрики отчёта, таблица отчёта.
7. Отступы между блоками `prof-card` / плитками в кабинете (в макете задаются правилом в `style.css`).

## Доработка существующего CSS, не новый элемент

Раскладка «сайдбар + контент» в `frontend.css` привязана к страницам-обёрткам (`.fs-all-tasks-page`, `.fs-articles-page` и др.), и те же правила сбрасывают стиль кнопок. Странице записи нужна своя обёртка в этом списке, но с кнопкой формы как у `fs-join-card`. В макете имитируется строкой в `style.css`.

## Решения, учтённые в макете

Нет капчи и OTP на гостевой форме; школа и класс из ссылки; «Перейти к оплате»; оплата, запись, допуск и попытка — отдельные пилюли; возврат вне Woo — только отметка; вход гостя — одна кнопка «Приступить»; экрана «Ссылка недействительна» нет (обычная 404); тренировки и перерешивания нет.
