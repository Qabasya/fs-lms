# Проверка макетов

2026-10-01. Проверены 13 экранов на 1440 px и 390 px.

Проверены: запись, перенос без немедленной отмены, самоотмена, состояния карточки, гостевая форма без OTP, персональный вход, использование существующей станции, №26 с 1/2, тренировка, выдача ссылки, школьный отчёт и встроенная read-only работа, утверждение, исправление, продление, родительский просмотр.

Ошибки JavaScript и горизонтальный выход страницы на мобильном: не обнаружены.

Это проверка HTML-прототипа. БД, реальные права, доставка уведомлений, согласия, таймер существующей станции и безопасность токенов здесь не проверялись и не реализованы. Их критерии перечислены в SPEC.md.
