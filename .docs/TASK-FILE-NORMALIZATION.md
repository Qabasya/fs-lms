# Имена файлов заданий

У опубликованного публичного задания файлы получают имя из номера задания: `1000.txt`, `1000-2.py`, `1000-3.pdf`. Нумерация общая для полей файлов и материалов из медиатеки. Один исходный файл, указанный несколько раз, копируется один раз. Уже присвоенные имена сохраняются при добавлении файлов.

Копии размещаются в `uploads/fs-lms/task-files/{предмет}/{ID задания}/`. При замене или занятом имени используется вложенный каталог `v2`, `v3` и далее. Исходные файлы и вложения остаются на месте, чтобы старые ссылки продолжали работать. Копии не удаляются автоматически; администратору не следует удалять их без проверки ссылок.

Нормализация работает после сохранения опубликованного задания, отложенной публикации и импорта предмета. Черновики и задачи приватного банка не меняются. Ссылки на внешние источники, недоступные локальные файлы и изображения медиатеки с миниатюрами пропускаются с предупреждением; удалённое хранилище без локального оригинала не поддерживается.

Для уже опубликованного банка сначала создайте резервную копию базы данных и uploads, а затем проверьте план:

```sh
wp fs-lms task rename-files --dry-run
wp fs-lms task rename-files --subject=inf --dry-run
wp fs-lms task rename-files --post-id=123 --dry-run
```

После проверки выполните команду в режиме обслуживания и сохраните вывод как журнал:

```sh
wp fs-lms task rename-files --subject=inf > task-files.log 2>&1
```

Вывод содержит ID задания, поля и вложения, старые и новые пути и ссылки. `--batch-size=100` задаёт размер выборки, `--after-id=123` позволяет продолжить после указанного ID. При ошибке или обнаруженном конфликте команда завершится с ненулевым кодом; после исправления её можно повторить. Если процесс прервался между копированием и сохранением, прежняя ссылка остаётся рабочей; повтор использует новый свободный каталог, а оставшуюся копию можно проверить по журналу.

При массовой смене номера прямые поля файлов и вложения `task_materials` обрабатываются вместе. При штатном откате массовой правки ссылки задания возвращаются к прежним, созданные копии остаются доступными по своим URL.
