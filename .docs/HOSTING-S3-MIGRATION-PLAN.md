## Цель и принятый способ

Перенести WordPress/fs-lms на новый хостинг, восстановить связь с офисным AdSync и полностью загрузить видео в новый S3 из локальных оригиналов. Пользователь вручную возвращает файлы из `<группа>/_uploaded/` в `<группа>/`. Отдельный режим сканирования архивов не нужен.

Сохраняем базу WordPress, идентификаторы занятий, записи видеореестра и ручные привязки. Повторная регистрация сообщает LMS новый бакет. Старый S3 и резервные копии сохраняются до приёмки.

**Просто вернуть файлы недостаточно:** загрузчик хранит `archived`/`registered` и `s3_key` в SQLite. Для нового S3 запускаем загрузчик с отдельным пустым каталогом состояния, сохранив старый. Не удаляем старый реестр и не сбрасываем статусы вручную.

**Фикс плагина готов локально, ещё не развёрнут:** повторная регистрация существующего `s3_key` обновляет бакет видеореестра, но ветка уже привязанного видео не обновляет `recording_url` занятия. Переподбирать занятие по дате не требуется: сохраняем существующую привязку, меняем только указатель хранилища.
