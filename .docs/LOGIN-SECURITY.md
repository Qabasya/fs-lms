# Защита входа и восстановление доступа

Изменения начинают действовать после выпуска и установки этой версии плагина.
WP-Cron для проверок и блокировок входа не нужен.

- Для недоверенного IP 20 неудачных попыток за фиксированное окно 10 минут
  создают постоянную блокировку IP. В IP-счётчик входят и отказы капчи, и
  повторные обращения во время блокировки. Доверенные адреса исключены.
- Для известного пользователя три ошибки пароля за пять минут с любых
  недоверенных IP создают постоянную блокировку учётной записи. Отказы капчи и
  других провайдеров, в том числе второго фактора, в этот счётчик не входят.
  Успешный вход очищает незавершённый счётчик, но не постоянную блокировку.
- Блокировка учётной записи не мешает входу с адресов из `FS_LMS_TRUSTED_IPS`.
  Список поддерживает точные IP, не диапазоны; его нужно проверить до выкладки.
  Капча для доверенного IP остаётся действующей.
- Неизвестные пользователи не получают постоянной блокировки учётной записи.
  Существующая временная защита пары «IP + пользователь» сохраняется.
- Данные блокировок находятся в БД и не очищаются по истечении времени или
  при перезагрузке. Для предотвращения потери параллельных попыток используются
  именованные блокировки MariaDB/MySQL. Промежуточные счётчики используют
  transient; их вытеснение кешем может сбросить незавершённое окно.

Администратор снимает блокировку IP в журнале «Аутентификация», указав адрес;
панель сообщает, был ли этот IP заблокирован; событие попадает в журнал.
Блокировка учётной записи снимается существующей
кнопкой в карточке пользователя. Для любого аккаунта и на случай потери доступа
к интерфейсу доступны команды на сервере:

```bash
sudo -u www-data wp --path=/var/www/future-step.ru fs-lms login unblock-ip 203.0.113.1
sudo -u www-data wp --path=/var/www/future-step.ru fs-lms login unblock-user 123
```

Постоянная блокировка IP и учётной записи снимается независимо. Если оба условия
сработали, необходимо снять оба. Для постоянной блокировки форма входа отключена
без таймера; после снятия блокировки страницу нужно обновить. Ротация `FS_LMS_HASH_SALT` меняет ключи всех
счётчиков и блокировок и может повлиять на другие данные плагина: не менять соль
без отдельного плана миграции.

Ограничение: атакующий может намеренно заблокировать известную учётную запись,
а общий внешний IP может объединять разных людей. Необходимы доверенный офисный
IP, работающий SSH-доступ администратора и проверка разблокировки до публичного
применения. Форма допускает резервный проход, если браузер сообщает об ошибке
загрузки капчи; это не замена второму фактору для привилегированных пользователей.
