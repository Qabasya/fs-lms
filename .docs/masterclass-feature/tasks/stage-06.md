## 6.1 Журнал на странице модуля

**Готово, когда:** вкладка открывается на стенде, фильтры работают.

## 6.2 Воронка

- [ ] `MasterclassFunnelDTO` в таблице `overview()`: создано → входили → вернулись домой → нажали «Связаться» → подали заявку → зачислены (по колонкам аккаунтов, удалённые
  тоже). Подписи и пустые состояния — текстом, без процентов-«красоты».
- [ ] Тест на MariaDB: `funnel()` после удаления неиспользованных аккаунтов сохраняет цифры «создано» и «входили».

**Готово, когда:** цифры на странице совпадают с ручным SQL по тому же мастер-классу.

## 6.3 Документы

- [ ] Записать в `.docs/ReleaseHistory_1.0.x.md` (раздел «9. Заявки и зачисление» или «14. Публичная часть сайта» — выбрать по месту) продуктовым языком: воронка школа →
  мастер-класс → вход дома → заявка → зачисление; временные аккаунты; заморозка по времени; почему отдельный модуль; вывод для второй версии одной строкой в «Выводы».
  Без имён классов, хуков, таблиц и номеров версий.
- [ ] Обновить `SPEC.md`/`CONTRACTS.md` по факту (имена, что сделано иначе), `inc/Modules/Masterclass/CLAUDE.md`, корневой `CLAUDE.md` (раздел «Модули»), `AGENTS.md`.
- [ ] Заполнить «Статус» всех этапов; отметки `[x]` только у проверенного.

**Готово, когда:** документы согласованы с кодом (`grep` имён из `CONTRACTS.md` по `inc/Modules/Masterclass/` находит каждое).
