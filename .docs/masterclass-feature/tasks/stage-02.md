# Этап 2. Создание мастер-класса, аккаунты, страница, флаеры

Зависимости: этап 1 (схема, репозитории, писатель журнала, подстраница), этап 0 (`lessonProblems`, `generateReadable`, Ш4).
Результат: офис создаёт и правит мастер-класс, добирает аккаунты порциями с прогрессом, печатает флаеры, продлевает, помечает к удалению,
снимает блокировки класса. Тика и плеерной части ещё нет.

Перед началом прочитать `README.md`, `../SPEC.md` §2 (решения 2–7, 14, 17, 21, 23), §4, `../CONTRACTS.md` §8 (`MasterclassService`,
`MasterclassAccountService`), §9 (`MasterclassAdminController`), §10–§11. Образцы страницы: `inc/Modules/AdSync/` (`assets/admin.js`, шаблоны).

**Порядок:** 2.1 → 2.2 → 2.3 → 2.4 → 2.5 → 2.6.

## 2.1 `MasterclassService`

- [ ] `create()`, `update()`, `extend()`, `requestDelete()`, `find()`, `overview()`, `lessonOptions()`, `teacherOptions()`, `serviceGroupIds()` — по
  `CONTRACTS.md` §8; `create()` в одной транзакции (`TransactionRunner`): группа (`AccessMode::Open`, `meetings = '[]'`, нет курса), занятие
  (`scheduled_at`/`ends_at` — местное, `visibility = open`, `opened_at = NULL`, снимок работ урока), строка `masterclasses`; журнал — **после**
  транзакции. Имя группы «Мастер-класс · {школа} · {дд.мм.гггг}», занято — « (2)», « (3)».
- [ ] Валидации: пустая школа; конец не позже начала; урок не найден / не опубликован / другого предмета / `OpenCourseValidator::lessonProblems()` не пуст;
  пользователь не `FSTeacher`; нет текущего периода. Тексты — для людей.
- [ ] `update()`: урок меняется только пока `GroupLessonUsageGuard::hasLearningData()` ложно; окно пересчитывает сроки и сбрасывает
  `frozen_at`/`unused_purged_at`; вычищенный/помеченный к удалению — исключение.
- [ ] Подключить Ш4: `MasterclassIntegrityController`/`MasterclassEnrollmentController` отдают `serviceGroupIds()` в `fs_lms_service_group_ids`
  (регистрация — в контроллере, который включается вместе с модулем; при выключенном модуле группа остаётся служебной — решить и записать сюда).
- [ ] Тесты: каждая валидация, порядок `create()` (группа → занятие → строка → журнал), откат при сбое занятия (группа не остаётся), `update()` синхронизирует
  преподавателя и расписание, `extend()` сдвигает сроки на одну разницу и сбрасывает `frozen_at`, `requestDelete()` возвращает число аккаунтов с заявкой.

**Готово, когда:** тесты зелёные; на MariaDB `create()` оставляет ровно группу + занятие + строку, при исключении посередине — ничего.
