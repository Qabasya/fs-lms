

### Главная ученика: «До экзамена» и плитки пилота (2026-10-30)

- **Даты экзаменов** — «Настройки → Экзамены → Даты экзаменов»: строка на предмет (`datetime-local`), хранится в `PluginConfig::examDates()` (`exam_dates`, `ключ предмета => ГГГГ-ММ-ДД ЧЧ:ММ`). Пустое поле снимает дату.
- **«До экзамена · предмет»** (`ExamCountdownSection`, до двух плиток): дальше недели — календарные дни, последние 7 суток — часы, красным (`.is-urgent`). Заменяет «Посещаемость» у ученика, пока у предмета его групп есть дата;
  без даты — «Посещаемость». **Родителю «Посещаемость» остаётся всегда** (для всех направлений). После экзамена плитка пропадает.
- **Пилот на `belova2024`** (`LearnerHighlightsSection`, фильтр `fs_lms_learner_highlights_logins`): «Серия без пропусков», «Осталось исправить» (сумма нерешённых заданий сданных работ из дедлайнов), «Последний результат»
  (последний утверждённый экзамен: ЕГЭ — вторичный балл, ОГЭ — отметка). Показываются только смотрящему из списка; чтобы включить всем — убрать проверку или расширить список фильтром.
- Проверено на dev через WP-CLI от лица belova2024 (person 26): две плитки «До экзамена» (часы, срочно), последний результат «20 · Осенний пробник». Не проверено в браузере: карточка настроек и вид плиток (нужны вход под учёткой и админка).
