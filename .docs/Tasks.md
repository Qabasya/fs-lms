# План: экран «Работы» — один список (2026-10-22)

Решения (владелец): три вкладки («На проверке» / «Проверенные» / «Прошедшие») убираем, остаётся один список работ прошедших занятий с фильтрами; всегда сначала новые (по дате занятия); порции по 10, остальное — по мере прокрутки; будущие занятия не показываем (заранее сданных работ у нас нет); экзамены и контрольные в список не входят (ведутся отдельно). Открытые группы без дат занятий попадают в список только при наличии сдач, датой служит последняя сдача.

- [x] **Сервис.** `PassedWorksService::feed()` — порция списка: занятия от новых к старым, закрывается целым занятием (может быть >10 работ), метка продолжения `next` («дата|ID занятия»), предел просмотра 40 занятий за запрос (редкий фильтр не перебирает историю). Строка — «занятие + работа» одной группы: `submitted / missing / pending`. Работа со сдачами остаётся в списке, даже если её убрали из набора занятия.
- [x] **Фильтры — на сервере:** группа, тип работы (`WorkType`), быстрый статус `pending` (есть сдачи на проверке) / `missing` (есть несдавшие). `pending_total` — только в первой порции (число у фильтра «Ждут проверки»).
- [x] **Репозиторий.** `GroupLessonRepository::listFeedPage()`: прошедшие занятия по группам, «дата» = `COALESCE(scheduled_at, последняя сдача)`, курсор `(дата, id)`; проверено на MariaDB (курсор, занятие без даты со сдачей, будущее занятие).
- [x] **Ученики работы** (`getPassedStudents`) отдают статус сдачи (`status`): не сдал / на проверке / оценена / возвращена / засчитана.
- [x] **Убрано:** `ReviewQueueService`, `ReviewQueueCallbacks`, AJAX `get_pending_works` и `get_work_submissions` (очередь и «Проверенные»; попытки контрольных из «Работ» уходят).
- [x] **Фронтенд.** `src/js/profile/works.js`: список без вкладок, подгрузка по прокрутке (`IntersectionObserver`, запасная кнопка «Показать ещё»), быстрый статус, тип и группа; фильтры помнятся в адресе (`works_g/works_t/works_s`); из тревоги главной «Работы без проверки» открывается с фильтром «Ждут проверки» (`applyWorksStatus()`). Зачёт и отмена зачёта перечитывают учеников и правят счётчики строки на месте.
- [x] **Тесты:** `PassedWorksServiceTest`, `PassedWorksCallbacksTest`, `GroupLessonRepositoryTest` (запрос ленты), `tests/js/profile-works.test.mjs`.
- [ ] **Не сделано в этой версии:** возврат из экрана проверки сразу в открытую работу (сейчас — в список с теми же фильтрами); серверные тесты на реальной MariaDB с большим числом занятий (замер на dev: порция 10–180 мс).
