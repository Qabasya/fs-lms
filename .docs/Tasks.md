Родитель имеет одну раскладку на всех детей. Плитки: `null` — автоматический набор, `[]` — всё убрано; явный набор сохраняет порядок. Новые плитки сами в главную не вставляются, добавляются через кастомизацию. Плитку «Дедлайнов» можно убрать.

## Согласованные правила рейтинга

1. Сравниваются ученики **всего предмета**, без разделения по группам, по реальному ключу предмета (`inf_ege`, `inf_oge`, `python`, `robo`), список не захардкожен. Рейтинг отдельный для каждого предмета.
2. Источник баллов — решённые задачи самостоятельных, экзаменов, опросов и домашних работ. По умолчанию одна решённая задача даёт **1 балл**, повторное успешное решение также даёт полный балл. У работ автор может задать цену каждой задачи; в рейтинг идёт сохранённая цена полностью решённой задачи × коэффициент типа работы. У формальных экзаменов одна полностью решённая задача по-прежнему даёт единицу × коэффициент экзамена, независимо от первичных баллов экзамена. Коэффициенты вынесены в отдельную политику начисления и настраиваются в «Настройки → Кастомизация → Рейтинг», чтобы менять их независимо от подсчёта мест. Несколько технических строк одного результата не должны повторно начислять балл.
3. Дата начисления — **сдача результата**, а для результата, требующего утверждения, — **утверждение**. Черновики и неутверждённые результаты, где утверждение обязательно, не участвуют.
4. Периоды: **сентябрь–ноябрь**, **декабрь–февраль** (с переходом календарного года), **март–май**. Счёт каждого триместра отдельный. Границы определяются по времени сайта.
5. При равном количестве баллов место одинаковое; используется плотная нумерация: 90, 90, 89 баллов → места **1, 1, 2**.
6. **Июнь–август: рейтинг не показывается**. Сохранённый выбор плитки остаётся в настройках до следующего учебного периода.
7. Плитка **«Рейтинг · предмет»**, иконка звезды, место ученика, количество баллов и название периода. У ученика входит в новый автоматический набор; родитель добавляет её вручную. Сохранённые явные наборы не изменяются. Нажатие пока не открывает отдельную страницу рейтинга.

## Оставшиеся пожелания и состояние выполнения

- [x] Рейтинг: серверный подсчёт по перечисленным источникам, вынесенная `RankingPointsPolicy` (отдельные веса самостоятельных, ДЗ, опросов, экзаменов), плотные места, периоды и скрытие летом. Состав предмета — ученики с активными записями зачисления; ученики с нулём баллов также участвуют. Тренажёр и промежуточные проверки до сдачи работы не начисляют баллы. Вес практики по умолчанию равен нулю и может быть изменён в настройках.
- [x] Плитка рейтинга в каталоге ученика/родителя; место, баллы, период, иконка звезды. Родитель видит рейтинг выбранного ребёнка. Добавляется через каталог и в автоматический набор ученика; летом скрывается с сохранением выбранного ID в явных раскладках.
- [x] **Статистика кастомизации в админке**: «Настройки → Кастомизация», право `ManageLmsPlatform`. Секции: «На первом / втором / третьем месте у N пользователей»; плитки: «Используется у N пользователей».
- [x] Статистика считает **сохранённые валидные раскладки существующих пользователей текущего сайта**. Без сохранённой настройки пользователь не учитывается. Автоматический набор плиток (`tiles: null`, в том числе после сброса) учитывается отдельно и не выдаётся за явный выбор каждой плитки. Пустой набор не добавляет использований. Временно скрытая, но выбранная плитка учитывается как предпочтение; это статистика настроек, а не показов. Повреждённые раскладки и роли без витрины исключаются.
- [x] **«Заменить»** рядом с «−»: две встречные стрелки, выбор другой доступной плитки из выпадающего списка, сохранение позиции. Если свободных вариантов нет, кнопка отключена.
- [x] **Кастомизация всех существующих витрин**: ученик, родитель, преподаватель, офисный администратор; сохранённые явные наборы сохраняются; у родителей и сотрудников прежние defaults, у ученика — новый набор по направлениям. Чистый WordPress-администратор использует офисную витрину; методист без роли с витриной отдельной главной не имеет.

## Настройка весов рейтинга

«Настройки → Кастомизация → Рейтинг», сохранение с правом `ManageLmsPlatform`:

| Поле | По умолчанию | Допустимое значение |
|---|---|---|
| Практика | 0 | 0–1000, до двух знаков после запятой |
| Самостоятельная работа | 1 | 0–1000, до двух знаков после запятой |
| Домашняя работа | 1 | 0–1000, до двух знаков после запятой |
| Опрос | 1 | 0–1000, до двух знаков после запятой |
| Экзамены и контрольные | 1 | 0–1000, до двух знаков после запятой |
| Бонус за серию посещений | 0 | 0–1000, до двух знаков после запятой |
| Занятий подряд для бонуса | 3 | Целое 2–100 |

Бонус начисляется за каждые N последовательных занятий без пропуска: 6 занятий при N = 3 дают два бонуса. Пропуск начинает новую серию. Нулевой бонус отключает начисление за посещаемость. Форма сохраняет только настройки рейтинга; показывает загрузку, результат и ошибки, блокирует повторную отправку, проверяет числа в браузере и на сервере.
