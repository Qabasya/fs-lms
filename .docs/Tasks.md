# План реализации (2026-10-20)

Решения: тема проведённого занятия заменяется без отдельного механизма данных (посещаемость и запись остаются, работы — нет); неиспользованная тема возвращается в пул как будущая; без уведомлений; доступно всем, кто правит КТП; точка после второго инициала («Иванов И.И.»); шаг «Трансляция» и плашка в шапке остаются; запоминание экранов — общий реестр, список легко расширяется; «Засчитать» = 1 балл (максимум), сдача ученика приоритетнее засчитывания; сводка ученика — только работы выбранного курса.
