## План реализации: публичные экзамены (ветка `feature/public-exams`, в релиз не тащим)

**Ветка:** `feature/public-exams`; версию не поднимаем, тег не ставим, в `master` не сливаем до отдельного решения.

### Решения (согласованы)

- **Только «ЕГЭ (Компьютер)»** (`AssessmentKind::EgeComputer`). ОГЭ и контрольные не трогаем ⇒ ручной проверки в публичных экзаменах нет.
- **Ничего не пишем в БД**: ни попыток, ни IP, ни таблицы, ни вкладки в «Журналах», ни лимитов, ни защиты от накрутки, ни ретеншна. Пункт про таблицу и «Журналы» из исходной постановки **снят**. Статистику собирает внешний плагин Метрики — плагину отдаём лишь DOM-события (см. C6).
- **Механика — «предпросмотр автора для всех»**: режим без попытки уже есть (`AttemptPageService::buildPreview()`, ответы в `localStorage`, `PreviewResultCallbacks` → `KegeResultSheetService::buildFromAnswers()`). Публичный режим = тот же путь + гость + без плашки автора.
- Один адрес: постоянная ссылка `{key}_assessments` остаётся. Есть доступ по курсу → курсовой путь (попытка в БД, как сейчас); иначе (гость и залогиненный без доступа) → публичный.
- Публичные экзамены индексируются (у публичных снимаем `noindex`).
- Раздел `/{key}/exams/` — по предметам; экзамены сгруппированы блоками по годам (как учебник по номерам заданий).
- Модуль `PublicExams`; зависит от `EgeComputer` (без него не работает и ничего не регистрирует).
- Без лимита прохождений. Правильные ответы после завершения показываются сразу (`AttemptRevealPolicy` не участвует — попытки нет).

### A. Ядро: поля конструктора и гейт страницы

- **A1. Поля метабокса экзамена** (`AssessmentTemplate` + `assessment-builder.js`, видны только при `kind = ege_computer`, по образцу `toggleKindFields()`):
  - `hide_intro` — «Скрыть приветственные экраны» (чекбокс, поле ядра — работает и в курсе). Смысл: ритуал станции (бланк → инструкция → КИМ → активация) пропускается, человек сразу попадает на первое задание. Значение по умолчанию **зависит от публичности**: пока мета не сохранена — эффективное значение = `is_public`; в конструкторе при включении «Публичный» галка ставится сама (пока автор не менял её руками). Старые экзамены не меняются (`is_public = false` → экраны есть).
  - `is_public` — «Публичный экзамен» и `exam_year` — «Год» (метка: поле ввода + подсказки `<datalist>` из уже введённых годов предмета, 4 цифры). Эти два поля добавляет **модуль** через новый фильтр `fs_lms_assessment_template_fields` (ядро о модуле не знает; выключен модуль — полей нет). Год обязателен при включённом «Публичный» (проверка при публикации, рядом с `EgeCompletenessChecker`).
  - Список существующих годов: метод в `AssessmentManager` (distinct `exam_year` по CPT предмета), выдаётся в конструктор через `AdminLocalizations`.
- **A2. `AssessmentDTO`**: `hideIntro` (эффективное значение с учётом `is_public`); публичные ключи модуль читает из меты сам (как `StationExamConfig`), в DTO их не тянем.
- **A3. `AssessmentPageController::loadTemplate()`**: перед редиректом гостя на логин спросить фильтр `fs_lms_assessment_public_access` (модуль отвечает `true` для публичного опубликованного ЕГЭ). Публичный → `buildPreview()` c новым флагом `publicMode` в `AttemptPageDTO` (не путать с `previewMode` автора); `noindex` (заголовок `X-Robots-Tag` и `<meta name="robots">` в `ege-computer.php`) — только не для публичного. Залогиненный без доступа по курсу и без права предпросмотра → публичный путь вместо 404, если экзамен публичный.
- **A4. `ege-computer.php`**: ветка `publicMode` — как предпросмотр (`exam.php` + `finish.php` + `entry.php`), но без `kege-preview-flag`; на `#kegeApp` атрибуты `data-public="1"`, `data-hide-intro`, `data-exams-url` (страница раздела). `data-preview` для публичного не ставим (проверить, что `disableCopying()` остаётся включённым).

### B. Модуль `inc/Modules/PublicExams/`

- **B1. Каркас:** `PublicExamsModule` (`ServiceInterface`), `Config/PublicExamsConfig extends ModuleConfig` (опция модуля, константа `FS_LMS_PUBLIC_EXAMS`, тумблер в Dashboard модулей — по образцу SmartCaptcha/DaData), регистрация в `Init::getServices()`. В `register()` сразу выходим, если модуль выключен или `EgeComputer` выключен.
- **B2. Гейт `PublicExamPolicy`:** экзамен публичен, если `status = publish`, `kind = ege_computer`, `is_public`, работа укомплектована (`EgeCompletenessChecker`). Единственная точка проверки для A3 и B3.
- **B3. AJAX `PublicResultCallbacks`** (`wp_ajax_` + `wp_ajax_nopriv_`, экшен — константа модуля, вне core `AjaxHook`): `Nonce::…->verify()` (для гостя — новый кейс `Nonce::PublicExam`), `PublicExamPolicy` → иначе `error`; дальше та же сборка листа, что в `PreviewResultCallbacks`. Общий код (санитайз `answers` + `buildFromAnswers()` + массив ответа) вынести из `PreviewResultCallbacks` в общий класс модуля EgeComputer, чтобы не дублировать.
- **B4. Публикация экшена в JS:** сейчас `BundleLoader::KEGE_PREVIEW_RESULT_FILTER` отдаёт имя экшена предпросмотра. Для публичной страницы фильтр возвращает экшен модуля (`publicMode` известен при энкью). Проверить, что `BundleLoader::enqueueKege()` и `fs_lms_kege_vars` (ajax_url, nonce) выдаются гостю.
- **B5. Данные раздела:** `PublicExamsDataBuilder` — опубликованные публичные ЕГЭ предмета → `[год => [карточки]]`, годы по убыванию, внутри года — по дате/названию. Доступ к данным через `AssessmentManager` (без прямого `WP_Query`). Кэш транзиентом с ключом-константой модуля, сброс на `save_post`/`delete_post`.
- **B6. Фильтры ядру:** `fs_lms_assessment_template_fields` (A1), `fs_lms_assessment_public_access` (A3), `fs_lms_subject_page_types` (D1), контент раздела (D2).

### C. Фронтенд станции (`src/js/kege/`)

- **C1. Режим `public`:** `kege-exam.js`/`kege-entry.js`/`kege-state.js` — ветка `data-public="1"` по образцу `preview` (ответы в `localStorage` `fsKegeSimV2:{id}`, «завершить» шлёт ответы на экшен из B4 и рисует лист поверх разметки `finish.php`).
- **C2. `hide_intro`:** при `data-hide-intro` ритуал не показывается, стадия сразу `exam`, первое задание открыто; в шапке и на `finish.php` скрыть «КИМ № / БР №» (нет ритуала — нет номеров).
- **C3. Таймер:** в публичном режиме идёт обратный отсчёт от `timeLimit` (235 мин) с момента старта (если экраны скрыты — с открытия страницы; если нет — с «Активации»). Абсолютный дедлайн (`deadlineTs`) пишется в `localStorage`, а не считается от загрузки страницы. **По нулю — автозавершение и переход на экран результатов** (переиспользовать `startCountdown(..., { onExpire: submit })`).
- **C4. Закрытие браузера / перезагрузка:** ответы уже копятся в `localStorage` — добавить запись на каждое изменение (debounce) и на `visibilitychange`/`pagehide`, хранить текущее задание и дедлайн. При возврате: дедлайн не вышел → продолжаем с тем же временем; вышел → сразу считаем результат по сохранённым ответам и показываем экран результатов.
- **C5. Общий компьютер (школы):** по «Завершить экзамен» и после показа результатов состояние экзамена стирается; перезагрузка страницы результатов даёт «Экзамен завершён» + «Пройти заново» (результат не хранится — принято). Незавершённая попытка при новом заходе: диалог «Продолжить прошлую попытку / Начать заново». «Завершить экзамен» на экране результатов ведёт на `data-exams-url`.
- **C6. События для Метрики (внешний плагин):** `document.dispatchEvent(new CustomEvent('fs-lms:public-exam-start' | 'fs-lms:public-exam-finish', { detail: { assessmentId, primary, primaryMax, secondary, autoFinished } }))`; глобалов `ym` не трогаем.
- **C7. Проверки:** `npm run lint:js`; SCSS для нового (диалог «Продолжить/Начать заново») — токены, `npm run lint:css`.

### D. Страница `/{key}/exams/`

- **D1. `SubjectPageType::Exams`** (slug `exams`, заголовок «{предмет} — экзамены», шорткод `ShortCode::SubjectExams`); `SubjectPagesService::ensureForSubject()/links()` + поле `exams` в `SubjectLinksDTO`. Раздел заводится только когда модуль включён (через `fs_lms_subject_page_types`); при выключении модуля страница не выдаётся (черновик), при включении — заводится/восстанавливается идемпотентно. Разовый прогон для уже существующих предметов (скилл `db-migrations`: самодостаточный класс, гейт своей опцией, вызов из `Init::run()`).
- **D2. Рендер:** `SubjectLandingController` регистрирует шорткод; содержимое подставляет модуль (фильтр). Шаблон `templates/frontend/subject/exams.php` (значение кейса = имя шаблона, см. правило про `SubjectPageType`).
- **D3. Дизайн:** как «Учебник по номерам»: блок на каждый год (заголовок «2026», по убыванию), внутри сетка карточек: **название** и кнопка «Приступить к экзамену» (ссылка на постоянную ссылку экзамена; тег-года в карточке не нужен — год задаёт блок). Пустое состояние — «Публичных экзаменов пока нет». SCSS — рядом с `_articles-page.scss`, только токены, без inline-стилей, иконки через `Icon`.
- **D4. Навигация:** ссылка на раздел на лендинге предмета и в крошках — только через `SubjectPagesService::links()`.

### E. Тесты и проверка

- **Unit:** `AssessmentDTO::hideIntro` (эффективное значение); `PublicExamPolicy` (опубликован/черновик, не ЕГЭ, не публичный, неукомплектованный); `PublicResultCallbacks` (гость проходит, непубличный/черновик отклоняются, нонс обязателен); `PublicExamsDataBuilder` (группировка и сортировка по годам); `AttemptPageService` — публичная страница не создаёт попыток.
- **Ручной сквозной тест (это и есть п. 3 постановки):** гость проходит ЕГЭ без авторизации → лист с ответами/баллами как в `kege_last.png`; экраны скрыты; автозавершение по таймеру; закрыл браузер → вернулся → ответы и время на месте; общий ПК — после «Завершить» чужое состояние не всплывает; студент с курсовым доступом идёт по прежнему пути (попытка в БД, ответы скрыты до утверждения); модуль выключен — конструктор, раздел и эндпоинт исчезают, курс работает как раньше.
- `npm run ci` (js/css/styles:check/phpunit).

### Порядок работ и риски

Порядок: A1–A2 → B1–B3 → A3–A4/B4 → C1–C2 → C3–C5 → D → C6/C7 → E → F.
Риски: (1) нонс для гостей и кэширование страниц (сайт без кеш-плагина — проверить); (2) публичный эндпоинт отдаёт эталонные ответы — только за `PublicExamPolicy`, других экзаменов не касается; (3) `SubjectPageType` — ядро: раздел включается модулем через фильтр, при выключенном модуле не заводится; (4) `localStorage` в приватном режиме/при блокировке — обернуть в try/catch (как в `kege-state.js`), без хранилища экзамен идёт, но без восстановления.
