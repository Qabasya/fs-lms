# Открытые курсы в «Моих курсах»: план реализации

Обновлено: 2026-11-05. Статус: фазы 1–4 реализованы и проверены локально;
выполняется фаза 5 — фильтры, отчёты и жизненный цикл. В production эти изменения не установлены;
проверка интерфейса в браузере и аудит production-БД ещё предстоят.
Здесь `[x]` означает подтверждённое решение или реализованный и проверенный пункт, `[ ]` — незавершённую работу.

## 1. Объём и принятые решения

- [x] Редактирование данных гостей экзамена отложено. В этот релиз задачу не включать.
- [x] Не создавать отдельный предмет для Git, Excel и каждого дополнительного курса.
  Использовать предмет «Общие курсы» с `hasBank=false`, без собственного банка заданий и статей.
  Это обычный предмет существующей модели, без нового специального типа предмета.
- [x] Аудиторию задавать отдельно каждому открытому курсу: по каким направлениям его показывать.
- [x] Доступные и уже начатые курсы показывать вместе в существующей карусели
  «Мои курсы» (`sc-tabs-wrap`, состояние `is-at-start` формируется существующим компонентом).
  Не создавать второй каталог или отдельный раздел «Доступные курсы».
- [x] До записи видны описание и программа, но уроки не кликабельны. В основной
  кнопке вместо «Продолжить» показывается «Приступить».
- [x] «Приступить» записывает текущего ученика в служебную открытую группу курса.
  Затем карточка работает как обычный курс: уроки, продолжение, прогресс и результаты.
- [x] Служебную группу и строки её программы сохраняем как основу существующей модели
  работ/попыток/прогресса. Новую независимую систему прохождения курсов не создавать.
- [x] Самозапись не отправляет писем, не создаёт аккаунтов и не запускает AdSync.
- [x] Только автопроверяемый контент, с существующими ограничениями OpenCourseValidator.
- [x] Общая группа сохраняет расписание, ручное добавление учеников, КТП, журнал,
  работы и сводку. В экзаменах и аналогичных выборах основной группы её нет.
- [x] Выбор «Общая» переносится из чекбокса в селект «Тип группы».

## 3. Настройки аудитории: где их задаёт автор

Добавить кнопку **«Доступ» в верхнюю панель конструктора курса**, рядом с существующими
параметрами курса/статусом. Она открывает компактную панель настроек:

1. Переключатель «Самостоятельное прохождение».
2. При включении — список направлений с множественным выбором:
   «Показывать ученикам направлений…».
3. Пояснение: «Курс появится в “Моих курсах”. Ученик начнёт его кнопкой “Приступить”».
4. Сохранение с видимым результатом и понятными ошибками валидации.

При создании курса не добавлять обязательный мастер настроек: новый курс по умолчанию
обычный и не показывается посторонним ученикам. Доступ можно настроить после создания
в той же панели. Пустой список направлений означает «никому», а не «всем».
Не использовать текстовое имя «Общие курсы» как условие доступа в коде.

До записи ученик видит только опубликованные и доступные по аудитории курсы.
Публикация курса и включение самостоятельного прохождения — разные действия.

Ограничения: согласованный срез использует транзакцию MariaDB и проверку
`@@session.in_transaction`. Если проверить отсутствие вложенной транзакции нельзя

считать гарантированно атомарным относительно таких изменений.
